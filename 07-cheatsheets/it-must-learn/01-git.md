# Git

Ngày đầu:

```bash
git add .
git commit
git push
```

Bạn nghĩ:

> “Git có gì khó?”

Cho đến khi:

CONFLICT

Rồi đồng nghiệp bảo:

> “Em rebase branch này rồi cherry-pick commit kia giúp anh nhé.”
>
> ...
>
> “Hay em nghỉ việc luôn có nhanh hơn không anh?”

Biết Git cơ bản là một chuyện. Làm việc với nhiều branch, merge conflict, rebase, revert, reset… lại là một câu chuyện khác.
