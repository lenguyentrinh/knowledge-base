# Mạng máy tính — Computer Networking

IP, TCP, UDP, DNS, HTTP, subnet, port, routing...

Ngày đầu học:

> “Em chỉ muốn code website thôi mà?”

Ngày production lỗi:

> “Sao localhost chạy mà server không chạy?”

Và thế là bắt đầu hành trình:

DNS → Firewall → Reverse Proxy → SSL → Port → Network → 3 giờ sáng vẫn chưa biết lỗi đâu.

Backend, DevOps, Cloud, Cybersecurity mà network yếu thì sớm muộn cũng gặp “nghiệp”.
