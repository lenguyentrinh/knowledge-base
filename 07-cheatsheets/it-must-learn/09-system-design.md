# System Design

Đây thường là lúc developer nhận ra:

“Code được feature”

và

“Thiết kế được hệ thống”

là hai level hoàn toàn khác nhau.

Load Balancer, Cache, Message Queue, Database Sharding, Replication, CDN, Microservices...

Interviewer:

> “Giả sử hệ thống có 10 triệu user thì em thiết kế thế nào?”

Ứng viên:

> “Dạ trước giờ project em có 17 user, trong đó 6 user là em tự tạo…”

🥲

Càng lên Senior/Lead thì System Design càng khó né.
