# Database & SQL

Ban đầu:

```sql
SELECT * FROM users;
```

Bạn:

> “SQL dễ mà.”

Một thời gian sau:

- JOIN 6 bảng
- index
- transaction
- isolation level
- deadlock
- execution plan
- query chạy 0,2 giây ở local nhưng 20 giây trên production

Lúc ấy SQL không còn “dễ thương” nữa.

Đặc biệt với Backend, Data, BA, QA… SQL gần như là kỹ năng rất khó né.
