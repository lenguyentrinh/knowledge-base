# Linux, Ubuntu và WSL:

Linux là một kernel (nhân của hệ điều hành) - phần giao tiếp trực tiếp với phần cứng, nó chịu trách nhiệm quản lý: CPU, RAM, tiến trình, ổ cứng, thiết bị(chuột, bàn phím, mạng). Nếu chỉ có kernel thì gần như user chỉ có thể khởi động máy tính mà gần như không có cách nào để thao tác với máy tính vì kernel chỉ làm nhiệm vụ quản lý tài nguyên, chứ không cung cấp giao diện hay công cụ để người dùng thao tác. -> Ubuntu

Ubuntu là một hệ điều hành hoàn chỉnh tức là tập hợp kernel + các thành phần khác(bash, package repository, driver, nhiều phần mềm khác,...)-các thành phần cần thiết để người dùng và ứng dụng có thể sử dụng máy tính

WSL giúp Windows chạy được Linux

sudo (cấp quyền admin), còn apt(package manager), docker daemon một tiến trình chạy ngầm
